# Getting help with Portico

Portico is maintained by volunteers, so answers can take a few days.

| You want to... | Go to |
|---|---|
| Ask how to install, configure or use it | [Discussions](https://github.com/AsteriaCreations/portico/discussions) |
| Report something that's broken | [New issue → Bug report](https://github.com/AsteriaCreations/portico/issues/new/choose) |
| Suggest a feature | [New issue → Feature request](https://github.com/AsteriaCreations/portico/issues/new/choose), or a Discussion if it's still an idea |
| Report a security problem | Privately, as described in [SECURITY.md](SECURITY.md). Never in a public issue. |

Before asking, these probably have the answer:

- [README](README.md): what Portico is, and setting it up locally.
- [docs/DEPLOYMENT.md](docs/DEPLOYMENT.md): installing it on a club's network.
- [docs/CONFIGURING.md](docs/CONFIGURING.md): every setting and feature flag.
- [docs/ADOPTING.md](docs/ADOPTING.md): running your own copy and taking updates.

When you post, include your Portico version (release tag or commit), and leave out member names,
dates of birth and notes, including in screenshots and log excerpts.
